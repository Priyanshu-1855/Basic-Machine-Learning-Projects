Basic Machine Learning Projects : 
This repository contains beginner-friendly machine learning projects implemented in Python using Jupyter Notebooks. Each notebook focuses on a different real-world problem and demonstrates the full ML workflow — from data preprocessing to model training, evaluation, and predictions.

Projects Included : 

1. Diabetes Prediction
--Predict whether a patient is diabetic or not using medical attributes.

Key steps:
-Data cleaning & preprocessing
-Exploratory data analysis
-Model training (Logistic Regression / SVM / RandomForest etc.)
-Performance evaluation
-Final prediction demo

2. House Price Prediction
--Build a regression model that predicts house prices based on various features.
-Highlights:
-Feature engineering
-Handling missing values
-Multiple regression models
-Error metrics (MAE, RMSE)

3. Spam Mail Detection
--Classify emails as Spam or Not Spam using NLP techniques.

What’s inside:
-Text cleaning (stopwords, stemming, tokenization)
-TF-IDF vectorization
-Naive Bayes / Logistic Regression classifier
-Accuracy & confusion matrix




🛠️ Technologies Used :
-Python
-Pandas
-NumPy
-Matplotlib / Seaborn
-Scikit-learn
-NLTK (for Spam Detection)


🚀 How to Run the Notebooks
Clone this repository:
-git clone https://github.com/Priyanshu-1855/Basic-Machine-Learning-Projects.git

-jupyter notebook

-- Run any .ipynb file.
